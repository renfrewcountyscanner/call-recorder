# Security

The backend runs as an unprivileged container user with a read-only root filesystem, dropped Linux capabilities, `no-new-privileges`, bounded processes and memory, and rotated container logs. A one-shot Compose service prepares `/app/call-recorder/runtime/audio` with mode 0750 and backend ownership; PostgreSQL uses `/app/call-recorder/runtime/postgres` with mode 0700. Sender API keys use a peppered HMAC-SHA256 verifier so ingestion cannot be turned into an attacker-controlled Argon2 workload; human passwords remain Argon2id. Upload and browser-session tokens are stored only as SHA-256 hashes. Sender filenames never select permanent storage paths, temporary uploads remain inside the configured storage root, and audio request bodies are size-limited and decoded with `ffprobe` before acceptance. Do not commit `.env`, runtime data, recordings, logs, API keys, or tokens.

Run production with `CALL_RECORDER_AUTH_REQUIRED=true` and local authentication enabled. Health/readiness and machine sender APIs remain separate: sender APIs require sender credentials, while browser routes require a local session. Never enable `CALL_RECORDER_ADMIN_OPEN` in production. Operational writes require an editor or administrator role; security-sensitive writes remain administrator-only.

## Web interface

All interface assets (CSS, JavaScript, HTMX, icons) are self-contained in the backend binary; no content is loaded from third-party origins. A strict Content-Security-Policy (`default-src 'self'`, no object embeds, form actions restricted to self), clickjacking protection, HSTS, cross-origin isolation headers, and `nosniff` are sent on every response. Mutation requests from local sessions require a session-bound CSRF token. Opaque sessions can be revoked centrally and expired records are cleaned periodically.

Notification destination secrets are environment-variable references; values are not stored in destination configuration. Webhook and SMTP connections resolve and dial verified addresses, reject private/link-local destinations by default, disable redirects, enforce timeouts, and require STARTTLS before SMTP authentication. Set `CALL_RECORDER_ALLOW_PRIVATE_DESTINATIONS=true` only when an administrator intentionally needs a private notification endpoint.
